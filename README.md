# SOC-Home-Lab
Using Splunk to detect simulated attacks on a Windows 11 VM
---
Designed and delpoyed a virtualized SOC lab environment using VirtualBox consisting of:
  - A Windows 11 endpoint configured with Splunk Universal Forwarder
  - An Ubuntu Server instance running Splunk Enterprise for centralized log ingestion and analysis
  - A Kali Linux VM used for attack simulation and security event generation
